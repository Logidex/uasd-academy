
# UASD Académica

Sistema de consulta académica de la
Universidad Autónoma de Santo Domingo.

## Objetivo

Permitir consultar facultades, escuelas,
carreras y planes de estudio.

## Tecnologías

- Java
- Spring Boot
- Maven
- SQLite (próximamente)
- React y TypeScript (próximamente)

## Ejecución del backend

Entrar en la carpeta Backend:

cd Backend

Ejecutar:

.\mvnw.cmd spring-boot:run

## Primera API

GET http://localhost:8080/api/hola
